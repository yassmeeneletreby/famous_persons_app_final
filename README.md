# Famous Persons App

Ready-to-open Flutter Android starter for the graduation project.

Open this folder directly in Android Studio as a Flutter project.

First command:
flutter pub get

Then run the app.

Current implementation:
- Home screen
- TMDB Popular Persons API
- Person model
- GridView
- Loading/error states
- Navigation to a placeholder Details screen

Next steps:
1. Person Details API
2. Person Images API
3. Full-screen image viewer + zoom + download
4. Favorites
5. Generative AI chat
